# wrf_demo / noobs

Fortran CALMET 6.5.0 golden for the WRF-demo case (NCAR Katrina tutorial wrfout subset).

- Grid: 12×12 @ ~28 km, UTM zone 14N
- Time: 2005-08-28 00–03 UTC (hourly; 3D.DAT temporally interpolated from 00/03Z WRF)
- Mode: `noobs`
- SURF/UP synthesized from wrfout near-surface / column (not real obs)
